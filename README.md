# Open Credits - Online College Credits Platform

A modern, responsive React web application for earning transferable college credits online.

## Features

- 🎓 Browse 200+ college courses
- 💰 Affordable tuition at $180 per credit hour
- 🔄 Transfer credits to 40+ partner universities
- 📱 Fully responsive design
- ⚡ Self-paced learning
- 🎨 Modern UI with smooth animations

## Components

- **Header**: Navigation and user actions
- **Hero**: Main landing section with CTA
- **Stats**: Key statistics and achievements
- **WhyOpenCredits**: Platform features and benefits
- **WorkProcess**: Step-by-step enrollment process
- **SchoolAcceptance**: University transfer verification
- **PopularCourses**: Featured course listings
- **PartnerUniversities**: Partner institution showcase
- **FAQ**: Frequently asked questions
- **Footer**: Site links and information

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.
